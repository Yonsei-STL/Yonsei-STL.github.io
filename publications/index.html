RM-MLLM: Robust Scene Understanding in Adverse Weather with RGB-Multispectral Fusion

Hyeongjin Ju, Sanghyeop Yeo, Incheol Park, Youngwan Jin, Yagiz Nalcakan, Shiho Kim

Results in Engineering, 2026

A multispectral multimodal language model and the DENSE-QA benchmark for adverse-weather driving scene understanding, using synchronized RGB and multispectral images.

Project pagePaper

RASMD: RGB And SWIR Multispectral Driving Dataset for Robust Perception in Adverse Conditions

Youngwan Jin, Michal Kovac, Yagiz Nalcakan, Incheol Park, Sanghyeop Yeo, Hyeongjin Ju, Shiho Kim

Information Fusion, 2026

A large-scale driving dataset of 100,000 aligned RGB-SWIR pairs, with benchmarks for object detection and RGB-to-SWIR translation in adverse conditions.

Project pagePaperarXivDataset

SpectraDiff: Enhancing the Fidelity of Infrared Image Translation with Object-Aware Diffusion

Incheol Park, Youngwan Jin, Yagiz Nalcakan, Hyeongjin Ju, Sanghyeop Yeo, Shiho Kim

Computer Vision and Image Understanding, 2026

A diffusion model that translates RGB images to infrared using semantic segmentation and a Spectral Attention Block, evaluated on FLIR, FMB, MFNet, IDD-AW, and RANUS.

Project pagePaperCode

Pix2Next: Leveraging Vision Foundation Models for RGB to NIR Image Translation

Youngwan Jin, Incheol Park, Hanbin Song, Hyeongjin Ju, Yagiz Nalcakan, Shiho Kim

Technologies, 2025

An RGB-to-NIR translation model that uses a vision foundation model, cross-attention, and a multi-scale PatchGAN, with results on RANUS, IDD-AW, and zero-shot BDD100K.
